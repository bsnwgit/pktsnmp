# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in pktSNMP, please report it privately using [GitHub's private vulnerability reporting](https://github.com/bsnwgit/pktsnmp/security/advisories/new) rather than opening a public issue.

Please include as much detail as possible:
- A description of the vulnerability and its potential impact
- Steps to reproduce
- Affected versions, if known

We'll acknowledge your report as soon as possible and work with you on a fix and disclosure timeline.

## Supported Versions

This project is actively developed on `main`. Security fixes are applied to the latest release only.
