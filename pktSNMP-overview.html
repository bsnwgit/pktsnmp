Ingest Pipeline

From Poll to Persistence

Each metric traverses a validated pipeline before hitting storage.

Step 01
Device Poll
otelcol SNMP receiver or pysnmp issues SNMPv1/v2c/v3 GET requests to managed devices on the configured interval.
→
Step 02
OTLP Batch
otelcol collects metrics into batches (~576 per batch), gzip-compresses, and POST to /api/snmp/ingest/otlp/v1/metrics.
→
Step 03
Decompress + Parse
pktSNMP detects gzip magic bytes, decompresses, and parses OTLP JSON. Extracts metric name, value, timestamp, and labels.
→
Step 04
Device Resolution
Metric path (SNMP/SITE/DEVICE/OID) matched against otelcol_label in the devices table to resolve device_id.
→
Step 05
Bulk Insert
Single executemany call writes the full batch to snmp_poll_results. Avoids per-row I/O overhead on EFS-backed storage.
→
Step 06
Alert Eval
Alert engine evaluates all enabled rules on a 60 s loop. Fires, deduplicates, auto-resolves, and dispatches notifications.
Capabilities

Platform Features

Everything needed to manage, visualize, and alert on SNMP data across your infrastructure.

📡
Multi-Mode Collection
Supports remote OpenTelemetry Collector instances (OTLP HTTP) and a built-in pysnmp local collector — both operating concurrently. Add and remove collectors from the UI without touching config files.
🏗
4-Level Device Hierarchy
Org → Group → Site → Device. Status rolls up automatically — a single downed device turns the parent Org red. Supports HA pairs (active/standby) and CSV bulk import/export.
📊
Rich Metrics UI
Per-device time-series charts for traffic (bps), packets/s, errors, discards, and interface speed. Status timelines, alert overlays, and CSV export. URL-synced device and time-range params for deep linking.
🔔
Intelligent Alert Engine
12 built-in rule evaluators covering interface down, flap detection, threshold breaches, bandwidth utilization, spike detection, trap events, and collector gaps. Auto-fires and auto-resolves with cooldown windows.
📣
Multi-Channel Notifications
Alert events deliver to in-app badge, email, Slack, PagerDuty, or custom webhook. Per-rule channel assignment. Notification log persisted to SQLite for full audit trail.
🤖
AI Assistant
Anthropic-powered natural language interface. Ask questions about device health, recent metrics, and alert history without writing a single query. Context-aware across your live device and event data.
🔐
Enterprise Auth
JWT access tokens (15 min) + httpOnly refresh tokens (7 days). Okta SAML 2.0 SSO integration. Role-based access control. SNMP community strings and v3 credentials encrypted at rest.
🗄
Switchable Storage Backends
Zero-config SQLite for most deployments. Switch to ClickHouse for high-volume environments or long-term retention. Backend selection persists in settings; switchover requires a service restart.
♻️
Automated Backup
Configurable schedule and retention policy from the Settings UI. On-demand via the REST API. Backs up both the control-plane and time-series SQLite databases to a configurable backup directory.
Alert Engine

12 Built-In Rule Types

Every rule fires, deduplicates, and auto-resolves — no manual close required.

Interface Down
ifOperStatus transitions to down
Interface Flap
Repeated up/down oscillation
Metric Threshold
Any OID value crosses a configured bound
Metric Spike
Sudden deviation from rolling baseline
Error Rate
ifInErrors or ifOutErrors rate too high
Discard Rate
ifInDiscards or ifOutDiscards rate too high
High Error Ratio
Errors as % of total traffic
Bandwidth Utilization
Link utilization % vs ifSpeed
Speed Change
ifSpeed changes unexpectedly
Collector Gap
No data received from a collector
Device Unreachable
No data for device beyond threshold
Trap Received
SNMP trap event from any device
